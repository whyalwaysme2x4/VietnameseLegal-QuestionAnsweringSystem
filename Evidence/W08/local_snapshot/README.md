# Local W8 evidence snapshot

Các JSON tại đây giữ nguyên bytes từ lượt tích hợp demo local ngày 25/11/2026, trước xuất bản. Manifest local chứa đường dẫn tương đối theo demo và không phải manifest của repo hiện hành. Không chạy validator của repo với manifest này. Dùng [manifest xuất bản](../manifest.json), [packaging](../packaging.json) và kết quả chạy trên code đóng gói tại Evidence/W08.

Không sao chép DB lịch sử, backup hoặc nội dung file được nhắc đến chỉ vì có tên/hash trong manifest local. Không coi snapshot này là lượt đo mới hoặc xác nhận model thật.
